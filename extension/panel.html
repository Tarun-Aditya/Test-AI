Connect to your hub

Autopilot runs your scenario with a hub: the server that understands the text, drives the page and keeps the results. Start one on this computer (see below) or use your team's.

This hub has accounts. Sign in once; Chrome keeps the cookie, the extension never stores your password.

How do I start a hub?

In the folder you downloaded, run ./start.sh (macOS, Linux) or start.bat (Windows). It opens at http://localhost:8000. Docker: docker compose up.

Before you start

  • Why the access? To click and type on the page for you, Autopilot uses Chrome's debugging interface on the tab you choose. It only touches a tab while a run or recording is active.
  • Chrome's "debugging this browser" bar appears during a run. Please don't press Cancel on it: that stops the run.
  • Your sites. Autopilot asks before it runs on a site you haven't allowed (change this in Settings).
