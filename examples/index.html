Practice pages

Static pages for trying Autopilot: point a test at them from Studio, e.g. Open http://localhost:8000/demo/shop/index.html. The example tests are in the examples/ folder.

  • DemoShopSearch, results, product page, quantity, cart. Used by shop_cart.txt with iterations.
  • Sign-up formRequired fields, length and range limits, error messages, and one planted bug (age 100 is accepted) for test design to find.
  • Demo appLog in (password secret), remember me, country, a hover menu. Used by login_test.txt.
  • Element playgroundEvery element type: nested shadow roots, nested iframes, random ids, dialogs, drag and drop, custom dropdown, date / range / colour, contenteditable, upload, late elements. Used by playground_test.txt (52 steps).
  • Lazy and virtual contentLazy sections and a virtualised list that only renders the rows in view.
  • Canvas checkoutControls drawn on a canvas: only the AI's screenshot fallback can find them.
